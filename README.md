# Resume Classification System

## Project Objective
Develop a robust machine learning system to automatically classify resumes into relevant job categories.

## SAMATRIX RESUMEFORGE 2026
This project is built for the SAMATRIX RESUMEFORGE 2026 hackathon.

## Problem Statement
Recruiters and HR departments receive thousands of resumes for various roles, and manually sorting through them is a time-consuming and error-prone process. The goal is to build an automated pipeline that can parse and classify resumes into distinct domains or job roles to streamline the hiring process.

## Dataset Description
The dataset consists of resumes in text format, along with their corresponding job categories.

## Planned ML/NLP Pipeline
* EDA
* Text preprocessing
* TF-IDF
* Logistic Regression
* Linear SVM
* Naive Bayes
* Word2Vec
* LSTM/GRU
* Model evaluation
* Error analysis
* Final prediction pipeline
* Streamlit demo

## Future Improvements
- Exploring more advanced LLMs for classification.
- Deploying the application to a cloud provider.
